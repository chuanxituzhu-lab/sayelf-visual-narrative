# Tension Engine

`TENSION` is the relationship between the `AVATAR` and the `METAPHOR` or the world around it. Do not merely place the character beside an object.

## Base relationships

```text
DISTANCE   the desired thing is visible but far away
PRESSURE   the world acts on the character
OBSTACLE   a real barrier blocks the next move
RELEASE    the character is separating from what was held
APPROACH   the character moves toward the unknown
EMBRACE    the character receives what used to be resisted
```

## Specify the relation

Write it as a verb or causal sentence:

```text
weak:  child + rain
strong: child stands inside the rain and stops hiding from it

weak:  figure + flower + cliffs
strong: figure wants the flower, but the abyss removes every obvious path
```

Then define the smallest action that can change the relation. The action becomes the candidate `TURN`; it must not solve the entire life problem.

## Tension check

- Can the relation be understood in one still?
- Is the obstacle or pressure concrete?
- Does the `TURN` alter the relation rather than merely add a visual effect?
