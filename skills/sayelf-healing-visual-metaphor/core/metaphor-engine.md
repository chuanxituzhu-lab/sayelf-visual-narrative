# Metaphor Engine

## Convert abstraction to one physical carrier

Choose one primary `METAPHOR` that can be seen, touched, moved, lit, or withheld. It carries the meaning; the environment supports it but does not compete with it.

| Abstract concern | Possible carrier | Keep the relationship visible |
| --- | --- | --- |
| acceptance | rain, wind, tide | the character stops resisting |
| hope | one flower, one distant light | the destination is visible but not solved |
| letting go | dry leaf, thread, paper boat | the grip releases without a speech |
| persistence | long path, repeated footprint | one more step occurs |
| choice | fork, doorway, two lights | one direction is selected |
| growth | nest edge, crack with a sprout | the character crosses a threshold |
| loneliness | far window, unanswered signal | distance receives a faint response |

The table is a seed list, not a template library. Choose a different carrier when the input makes the relation clearer.

## One-carrier test

Remove the candidate object. If the image loses the emotional mechanism, keep it. If the image still works or becomes clearer, the object was decoration and must go.

## Avoid symbol piles

Do not combine a flower, sunrise, butterfly, rainbow, open door, bird, and path to “show hope”. One carrier plus one relationship is stronger than a collection of familiar symbols.
