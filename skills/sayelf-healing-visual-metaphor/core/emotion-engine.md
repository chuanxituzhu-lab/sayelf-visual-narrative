# Emotion Engine

## Choose one feeling

Use the user's wording to select one dominant `FEEL`. The v0.2.2 domain labels are:

```text
healing / life insight / hope / loneliness / persistence
letting go / choice / growth / acceptance
```

Translate broad labels into a felt state when useful: `hope` may become “quiet expectation”; `letting go` may become “release without certainty”. Do not stack them as co-equal emotions.

## Define the unresolved state

`WOUND` is what has not yet changed when the story begins. It is a narrative condition, not medical or mental-health advice.

Use this pair:

```text
FEEL  = what the audience should feel
WOUND = what the character is still unable to do, face, accept, or release
```

Examples:

| FEEL | WOUND |
| --- | --- |
| acceptance | resisting a world that cannot be controlled |
| hope | seeing a destination but no path |
| persistence | stopping one step before continuing |
| letting go | still holding what has already ended |
| loneliness | being surrounded by distance with no response |

## Failure modes

- If the input contains several lessons, choose the one that can be shown by one relationship and keep the rest out of v0.2.2.
- If the feeling is only named and has no condition, infer a minimal `WOUND` and label it as a director inference internally.
- If a proposed `FEEL` needs narration to be understood, it is not yet visual enough.
