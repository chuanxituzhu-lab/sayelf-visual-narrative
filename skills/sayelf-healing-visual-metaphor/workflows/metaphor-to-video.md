# Workflow: Metaphor → Five-Shot Video

Video explains how the Hero Image moment happens; it is not a still image with random motion added.

## Sequence

1. Lock the shared identity, world, metaphor, palette, light, and aspect ratio.
2. Plan exactly five functions: `WORLD / WOUND / TENSION / TURN / AFTERGLOW`.
3. Allocate a short duration to each shot; default total is 10–12 seconds.
4. Give each shot one framing and one primary motion. Add at most two environmental micro-motions.
5. Reserve the only strong escalation for Shot 04. Keep Shot 05 held and unresolved.
6. Write sound as an evidence cue: ambience, one decisive sound, and restrained music entry/exit only if it supports the peak.
7. Write one video prompt per shot. For image-to-video, say “preserve composition, identity, colors, and lighting” before describing motion.
8. Run `CONTINUITY LOCK`, `MOTION BUDGET`, `EMOTIONAL PEAK LOCK`, and `NO PREACHING` checks.

## Repair rule

If a shot fails, change one variable at a time: identity block, action, camera move, negative constraint, or reference frame. Do not add a new event or new style system to compensate.
