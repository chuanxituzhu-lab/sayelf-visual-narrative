# Workflow: Local Reference Image → Metaphor → Dual Output

Use when the user provides an image or screenshot as a visual reference.

## Read the reference

First record only visible `Observation`:

```text
subject / environment / light / palette / composition / action / visual contrast
```

Then make a separate director `Inference` about the likely feeling and relationship. A candidate `TURN` remains a `Hypothesis` until it passes the no-text readability and frozen-lock checks.

## Preserve the right thing

- Preserve the visual mechanism, not accidental app chrome.
- Treat platform UI, captions, logos, watermarks, counters, and usernames as noise unless explicitly requested.
- Keep one primary style contrast and one metaphor; do not copy every visible object.
- Use the reference as a local input. Do not upload it, fetch a remote duplicate, or expose its metadata by default.

## Finish

Convert the validated interpretation into the normal semantic block, then produce the same Hero Image + five-shot video Contract. If the reference already shows the climax, use it as a `MOMENT` anchor and design earlier shots that causally lead to it.
