# Workflow: Text → Metaphor → Dual Output

Use for a sentence, emotion, life insight, or short story.

1. Rewrite the input as one `CORE` proposition without advice.
2. Select one `FEEL` and define one `WOUND`.
3. Choose one anonymous `AVATAR`, one believable `WORLD`, and one physical `METAPHOR`.
4. State the `TENSION` as a relationship verb or causal sentence.
5. Define one `TURN` and freeze its `MOMENT`; define what remains unresolved as `AFTERGLOW`.
6. Choose one style reference.
7. Generate the Hero Image prompt and five-shot storyboard using [core/output-contract.md](../core/output-contract.md).
8. Apply all frozen locks and return the final package.

If the input is broad, make one reasonable assumption and keep all other possible themes out of the v0.2.4 package.
