# Frozen Rule: MOTION BUDGET

Each shot gets:

```text
1 primary motion
+ no more than 2 environmental micro-motions
```

Camera movement counts as the primary motion when it is the shot's main event. A tightly causal chain inside the `TURN`—for example, one raindrop impact causing one splash and one synchronized arm-opening response—counts as one decisive beat, not a license for independent simultaneous actions. Do not animate every object.

Write the budget explicitly in each storyboard row so it can be checked before generation.
