# v0.1 Frozen Locks

These four rules are hard constraints, not style suggestions:

1. `CONTINUITY LOCK`: identity, world, metaphor, light, and visual treatment remain stable.
2. `MOTION BUDGET`: one primary motion plus at most two environmental micro-motions per shot.
3. `EMOTIONAL PEAK LOCK`: one main peak, at `TURN`; no new event after it.
4. `NO PREACHING`: no moral text, therapy claim, direct explanation, or forced resolution.

Read the focused files in this directory when drafting or checking the package. If one lock conflicts with a decorative idea, remove the decorative idea.
