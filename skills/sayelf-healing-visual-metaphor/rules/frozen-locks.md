# v0.2.4 Frozen Locks

These five rules are hard constraints, not style suggestions:

1. `CONTINUITY LOCK`: identity, world, metaphor, light, and visual treatment remain stable.
2. `ACCOUNT CHARACTER LOCK`: exactly one account profile is selected; its silhouette and treatment do not drift.
3. `MOTION BUDGET`: one primary motion plus at most two environmental micro-motions per shot.
4. `EMOTIONAL PEAK LOCK`: one main peak, at `TURN`; no new event after it.
5. `NO PREACHING`: no moral text, therapy claim, direct explanation, or forced resolution.

Read the focused files in this directory when drafting or checking the package. If one lock conflicts with a decorative idea, remove the decorative idea.
