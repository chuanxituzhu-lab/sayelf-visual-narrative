# Style: Realistic World + Hand-Drawn Cartoon Avatar

Use when the emotional carrier benefits from warmth, innocence, or an immediate audience proxy. The world stays physically believable; the avatar stays intentionally simple.

## Style lock

```text
photorealistic environment and physically believable materials
+ tiny anonymous hand-drawn 2D character
+ simple black ink outlines, sparse features, readable silhouette
+ no realistic face, celebrity likeness, or detailed costume design
```

## Best for

Acceptance, joy under pressure, childhood resilience, and gentle growth. The rain-acceptance example uses this style.

## Prompt guard

Name the contrast explicitly in both image and video prompts: realistic world, deliberately simple hand-drawn character. Do not let the generator render the character as a photoreal human or turn the world into a flat cartoon background.
