# Style: Realistic World + Luminous Line Avatar

Use when the protagonist should feel anonymous, symbolic, and easy to read against a large dark environment. If the account profile is `NEON-LINE-01`, use that profile's fixed compact neon raindrop identity rather than a generic line figure.

## Style lock

```text
cinematic realistic landscape
+ one minimal human figure drawn only with thin cyan-blue luminous lines with a restrained violet inner glow
+ small smooth teardrop body, articulated upper arm/forearm/palm and thigh/shin/foot
+ two dot eyes and one curved smile
+ restrained glow with readable body pose
```

## Best for

Hope, loneliness, choice, distance, and a visible but unresolved destination. The cliff-hope example uses this style.

## Prompt guard

Keep the line figure's compact teardrop body, proportions, cyan-blue outer contour,
restrained violet inner glow, two-dot face, and articulated limb grammar consistent
across all shots and all settings. Actions may change through readable elbow, wrist,
knee, ankle, palm, and foot angles, but appearance does not. Do not add realistic
anatomy, clothing, extra people, costume changes, or decorative light trails.
