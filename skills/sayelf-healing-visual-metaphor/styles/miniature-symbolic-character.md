# Style: Miniature Symbolic Character

Use when the character should function primarily as a scale marker and emotional proxy inside a large, credible world.

## Style lock

```text
one tiny anonymous figure
+ simplified silhouette or single graphic treatment
+ large quiet environment with clear scale contrast
+ restrained detail and one readable gesture
```

## Best for

Persistence, solitude, release, and threshold moments where the world is larger than the person.

## Prompt guard

The character must remain legible at the chosen framing. Do not add a second protagonist, a crowd, or detail that competes with the metaphor. Choose either silhouette, line, or cartoon treatment for the whole package.
