AI-native nature visual grammar

Hidden Nature Window

进入 → 包围 → 引导 → 显露

从自然内部发现世界。以小昆虫般的低位视角沿植物缝隙向上，自动找到蓝天、朝霞或晚霞；其余视觉细节由系统匹配。

◌

01 / Configure

从场景开始Start with a scene

不需要理解规则。选好场景后，系统负责匹配细节。

普通用户无需理解规则：选好场景和画面比例即可，系统会自动匹配视觉钩子、情绪、隐藏窗口与色彩策略。

高级设置：选择自动匹配或自定义

高级用户可填写需要改变的项目；留空的项目仍由系统自动匹配。

02 / Compose

动态场景组合Scene Composer

可以自动选择、随机组合，也可以由高级用户手动指定。

03 / Reveal

生成结果Prompt + ratio preview

提示词与视觉参考并置，方便理解、复制和继续创作。
